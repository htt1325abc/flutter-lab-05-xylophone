# Lab 5: Xylophone

## Mô tả

Ứng dụng mô phỏng đàn Xylophone với bảy phím màu. Mỗi phím phát đúng một file âm thanh tương ứng từ assets.

## Chức năng

- Hiển thị bảy phím với bảy màu khác nhau
- Phát note từ DO đến SI
- Dùng `Expanded` để các phím lấp đầy màn hình

## Công nghệ

- Flutter
- Dart
- audioplayers

## Cách chạy

```bash
flutter pub get
flutter run
```
